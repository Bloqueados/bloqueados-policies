## 📱 Acerca de Bloqueados

Bloqueados es una aplicación móvil para iOS que protege contra llamadas spam en Chile mediante bloqueo automático de números no deseados.

### Características:

- ✅ Bloqueo automático de spam chileno
- ✅ Privacidad garantizada (no recopilamos datos)
- ✅ Sin anuncios
- ✅ Fácil de usar
